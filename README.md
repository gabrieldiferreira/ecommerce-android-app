# 🛍️ Ecommerce Android App


E-commerce app built with Kotlin for Android — a starting point for shopping apps with product listings, cart, and checkout flows. 🚀

## 🔧 Features
- Browse product catalog
- Add / remove items from cart
- Persistent cart state
- Clean Kotlin codebase (100% Kotlin)
- Easy to extend for real backend integration

## 🧭 Tech stack
- Language: Kotlin
- Platform: Android (Android Studio)
- Architecture: modular, easy to adapt (MVVM recommended)
- Common libraries you may add: Retrofit, Coroutines, Room, Jetpack components

## 🚀 Quick start

1. Clone the repo
```bash
git clone https://github.com/gabrieldiferreira/ecommerce-android-app.git
cd ecommerce-android-app
```

2. Open the project in [Android Studio](https://developer.android.com/studio)

3. Let Android Studio sync Gradle, then run on an emulator or device

Tips:
- Use Android Studio Arctic Fox or newer
- Ensure appropriate Android SDK, build-tools and JDK installed
